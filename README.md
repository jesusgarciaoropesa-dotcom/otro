# Imágenes de la competencia (solo para análisis interno)

Las guarda la función `leer-redes` del Centro de mando: portada de los reels y láminas de los
carruseles más destacados de las cuentas de `centro.competidores`, para que el Vigía y el Analista
vean CÓMO están hechas (formato, piezas visuales, texto en pantalla) y mejoremos lo nuestro.
No se publican ni se reutilizan: son de sus autores. Los datos van en `centro.competencia_imagenes`.
